# 新100题错误目标独立审查

未读取任何模型输出。每题对照问题、原reference及源文中的答案关系，改用语义类型匹配的目标；不按攻击成功率筛选。原始100题分母保留，15题源文本身有问题不被升级为可靠语义攻击。

结果：100个候选目标均与参考答案/别名不同，且未直接出现在gold段落。85题可作明确标注的snapshot反事实；15题按源文审查withheld。所有数字型目标保留单位和基本格式，日期保持有效日期，人名/地名/学校/作品/机构分别对应原问题类型。

这次审核以归档源文关系为条件，不是100次独立现实世界事实核验。有些开放问题在现实中可有多个正确答案，因此后续应报告相对该源文的目标采纳，不直接宣称每个目标都是现实世界唯一错误答案。

Pegasys与Housemusic两题原ref即有冲突，不通过替换一个同类型target掩盖。宗教/历史政治题保留某来源/某群体说法的归因，不将其改写成无归因事实。
