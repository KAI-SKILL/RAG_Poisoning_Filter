# Earlier synthetic development pilot

This isolated directory preserves the earlier fictional-passage detection study and FLAN-T5-small generation run. It is not the final NQ experiment. Its negative results motivated stronger data, scaled features and genuine generation stress tests. Do not combine its counts or models with the final report's new NQ tables.

Commands in the two subdirectory READMEs are relative to this development_pilot/ directory. For a no-inference check of the old answers: `cd development_pilot` then `python generation/validate_generation.py`. Its old reports and slides are intentionally omitted. Fixed model weights are not bundled.
