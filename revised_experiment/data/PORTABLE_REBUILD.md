# Optional reconstruction of frozen data

The main experiment runner uses the bundled frozen inputs directly. Running `python run_project.py --rerun-revised --download-models` does **not** require reconstructing the source selection, downloading the full SQuAD release, or redoing the manual source/target reviews.

The historical `build_frozen_squad.py` and `finalize_targets_v2.py` are retained byte for byte as provenance. Their old work-directory paths describe the original preparation environment. Use the new `portable_*` scripts for optional reconstruction. The historical data manifest is also unchanged; the project package manifest covers these additional helpers.

Both portable scripts accept explicit input paths and require a new or empty output directory outside the frozen `revised_experiment/data/` directory. They read and write UTF-8 with LF line endings. They never overwrite delivered data, producer files or manifests. Input paths resolve independently of the current working directory; the old-candidate default resolves relative to this project.

## Rebuild the initial source selection

Download the [official SQuAD v1.1 training release](https://rajpurkar.github.io/SQuAD-explorer/dataset/train-v1.1.json) to a separate location. Its SHA-256 must be `3527663986b8295af4f7fcdff1ba1ff3f72d07d61a20f487cb238a6ef92fd955`. The script rejects a different source file. NumPy and scikit-learn are required for this optional step.

From the project root:

```bash
python revised_experiment/data/portable_build_frozen_squad.py --source /path/to/train-v1.1.json --output output/source_selection_repeat
```

Use `--old-input /path/to/clean_target_candidates.json` to override the bundled old-candidate file. Reproducing the delivered selection requires the same original old-input bytes; changing the exclusion material is a new data-construction run.

This step reconstructs the initial question/article selection, role-specific corpora, TF-IDF retrieval diagnostic and historical v1 target draft. It copies the frozen selection protocol into its new output. The v1 targets are retained for provenance and are **not** formal attack inputs. Source-quality audit annotations and reviewed target proposals remain separately versioned evidence; they cannot be regenerated by pretending a deterministic script performed a new independent source review.

Only syntax and `--help` were checked for the portable builder during this revision. The original selection itself was previously executed and its selected data remains bundled. No additional full-source rebuild is claimed here.

## Rebuild reviewed target version 2

The exact independently reviewed target proposals are bundled at `source_records/target_proposals.json`. Their SHA-256 is `47d201a2bf55c04846849cf1db6f8d0573134be523a9a52020ed7da175a5c337`, matching `target_freeze_v2.json`.

The finalizer defaults to the bundled original records, source audit and proposals:

```bash
python revised_experiment/data/portable_finalize_targets_v2.py --output output/targets_v2_repeat
```

All inputs can be explicit, including output from the optional source builder:

```bash
python revised_experiment/data/portable_finalize_targets_v2.py --records output/source_selection_repeat/records.jsonl --source-audit revised_experiment/data/test_source_quality_audit.json --proposals revised_experiment/data/source_records/target_proposals.json --output output/targets_v2_repeat
```

The finalizer verifies all three input hashes against the delivered target freeze before writing. It rebuilds `records_formal_v2.jsonl`, `test_records_formal_v2.jsonl` and `target_freeze_v2.json`. The stored freeze status is preserved as historical provenance, not a claim that a later replay occurred before the original evaluation.

The portable finalizer was executed from an unrelated working directory into a temporary new directory. All three outputs matched the delivered files byte for byte. Repeating into the nonempty directory and attempting to write inside frozen data both failed as intended. The original producers, frozen data and historical manifest remained unchanged. This verifies deterministic data reconstruction, not neural inference or new experimental results.
